Backup & Restore

Cadangkan seluruh data WMS ke file, atau pulihkan dari file backup (khusus admin)

📦 Ringkasan Data

Jumlah data per koleksi saat ini di sistem.

⬇️ Backup Data

Mengunduh SELURUH data sistem (semua yang muncul di "Ringkasan Data" di atas — Master Barang, semua jenis transaksi, User & Role, Log Aktivitas, dst) dalam satu file JSON. Simpan file ini di tempat aman (Google Drive/HP) secara berkala.

📊 Backup ke Excel

Cadangan cadangan berupa file Excel (.xlsx) yang bisa langsung dibuka & dibaca — buat jaga-jaga kalau aplikasi/Firebase lagi down, data tetap aman & bisa dicek manual di Excel/HP. Satu sheet per jenis data, jadi tidak perlu salin satu-satu. Catatan: file ini untuk dibaca-baca saja, bukan untuk di-restore balik ke sistem (kalau butuh restore ke sistem, pakai file JSON di atas).

⬆️ Restore Data

Perhatian: Restore akan menimpa data yang ID-nya sama persis dengan isi file backup. Data lain yang tidak ada di file backup tidak akan dihapus. Disarankan backup dulu sebelum restore.

🔗 Gabungkan Barang
